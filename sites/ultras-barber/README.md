# Ultras Barber · ejemplo de WhatsApp (demo)

Muestra para Mohamed, dueño de Ultras Barber (barber shop en el 18e de París). Reciclada de
`sites/latins`, toda en francés, con el cartel «Exemple» arriba.

- Un chat: el cliente pregunta si hay lugar hoy para corte + barba, el asistente da el precio, ofrece
  dos horarios de hoy y confirma el turno.
- Del negocio solo están el nombre, el barrio y el nombre del dueño. El precio (30 €) y los horarios
  (16h15 / 18h00) son inventados y están marcados como ejemplo: no agregar dirección, teléfono,
  reseñas ni barberos hasta tener los datos reales.
- Si nadie toca un horario, sigue con el de ejemplo. Después, tocar el otro rehace el final.
- Un solo `index.html` con el CSS y el JS dentro. `og.jpg` es la miniatura al compartir el link.

## Enlaces para la demo

- `?wa=33612345678` muestra al final «Parlons-en sur WhatsApp» (wa.me a ese número, con el mensaje
